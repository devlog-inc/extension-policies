# Scene Volume プライバシーポリシー

最終更新日：2026年11月24日

Scene Volume（以下「本拡張機能」）は、株式会社デブログ（DEVLOG Inc.、以下「当社」）が提供する Google Chrome 用の拡張機能です。本ポリシーでは、本拡張機能が扱う情報と、その扱い方を説明します。

## 1. 扱う情報

本拡張機能が扱う情報は、次のものだけです。

| 情報 | 使い道 | 保存する場所 |
|--|--|--|
| 利用者が作った場面の設定（場面の名前・アイコン・バッジ、サイトのドメイン名と音量） | 場面ごとに、サイトの音量を切り替えるため | Chrome の同期ストレージ（chrome.storage.sync） |
| 今どの場面を使っているか | 今の場面の音量を当てはめるため | その端末の Chrome の中（chrome.storage.local） |
| 開いているページのドメイン名 | そのサイトに当てはめる音量を決めるため | ふだんは保存しません。ポップアップでそのサイトの音量を変えた時だけ、そのドメイン名を場面の設定として保存します（上の行の「サイトのドメイン名」） |

## 2. 外部への送信

本拡張機能は、上の情報を当社や第三者のサーバーに送信しません。分析ツールや広告も使っていません。

Chrome の同期をオンにしている場合、場面の設定は Google アカウントを通じて利用者のほかの端末と同期されます。この同期は Chrome の機能で行われ、Google のプライバシーポリシーに従って扱われます。

## 3. 集めない情報

本拡張機能は、閲覧履歴、ページの内容、入力した文字、個人を特定できる情報を記録・収集しません。ページの中で動くスクリプトは、動画・音声の音量を調整するだけです。

なお、音量を調整する仕組み上、開いているページのスクリプトから、そのページに掛けている音量の倍率（0〜100%）を読み取れる場合があります。倍率のほかに、場面やほかのサイトの設定がページに渡ることはありません。

## 4. 情報の削除

場面やサイトの設定は、本拡張機能の設定画面からいつでも消せます。本拡張機能を Chrome から削除すると、その端末の Chrome の中に保存された情報は消えます。Google アカウントに同期された情報は、Chrome の設定から同期データを削除すると消せます。

## 5. 本ポリシーの変更

本拡張機能の情報の扱い方を変える時は、本ポリシーを更新し、上の最終更新日を改めます。
